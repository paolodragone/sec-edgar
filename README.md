# SEC EDGAR API Client

A small client to fetch 10-K reports from the SEC EDGAR API.

This code can be used as a library to query EDGAR endpoints directly or as an app to fetch the latest 10-K reports for several major companies.

## Quick start

The recommended way to run the download script is via Docker.

First build the image locally by navigating into the project's top-level directory and run:
```
./build.sh
```

After the build script has complete, you can run the download script with:
```
./run.sh
```

The script will run in approximately 2 to 5 minutes (the script heavily rate-limted to adhear to the SEC guidelines, plus PDF generation with WeasyPrint takes a little while).

The output directory is set to "./reports" by default, that's where the PDF files will be downloaded.

The file names will be of the format `"{ticker}_10k.pdf"`.

To call the script with a different set of tickers you can pass a different list via command-line:
```
./run.sh --tickers NVDA TSLA WMT ORCL
```

Or you can use a text file with one ticker per line and run:
```
cat tickers.txt | xargs ./run.sh --tickers
```

## Requirements (without Docker)

In case you want to run the script without Docker, or you want to run unit tests or integrate this code into another project, these are the requirements:

- Python 3.12+
- [WeasyPrint](https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#installation) (for PDF printing)
- uv (optional, for convenience)

## Setup and run (without Docker)

If using uv, you can run the script directly, the virtual environment and dependencies will be downloaded on the fly:
```
uv run -m edgar.main
```

If not using uv, I included an autogenerated `requirements.txt` file to install all dependencies via pip.
It's recommended to use a virtual environment:
```
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

After installing dependencies you can run the script as:
```
python -m edgar.main
```

All options described above are still available to run with the script without docker.

## Test

Unit tests are developed using pytest, you can run them with uv:
```
uv run pytest
```

or without uv (after installing the requirements):
```
pyest
```

## Code structure

The `edgar` package contains the following files:
```
- api.py
    An API client to execute basic requests to the SEC EDGAR API; also implements rate-limiting and identification logic (user-agent).
- logging.py
    Enable structured logging to be used throughtout the project.
- main.py
    The main entrypoint of the downloader script.
- printer.py
    Utilities using WeasyPrint to download webpages in PDF format.
- reports.py
    The main logic of the reports downloader.
- types.py
    Type definitions used throughout the project.
```

Unit tests are located in the `tests` subdirectory.
